## Checklist de qualité

- [ ] Aucun fait ne dépend d'une interprétation psychologique ou d'un stéréotype.
- [ ] La bonne preuve réfute la proposition **après** précision, si nécessaire.
- [ ] Le leurre ne prouve pas accidentellement la réponse.
- [ ] Les dates et durées sont vérifiées ; les alternatives plausibles sont écartées.
- [ ] Les affirmations vraies restent crédibles et correctement documentées.
- [ ] Aucun indice d'une affaire ne casse une autre affaire.
- [ ] Phrases LU naturelles, niveau A1.1/A1.2, contrôlées sur LOD/grammaire.
- [ ] Identifiants, structure JSON, moteur, progression et renderer conservés.
- [ ] Tests et recette selon SPEC 110 et PLAYBOOK exécutés.
- [ ] Validation éditoriale / produit obtenue avant clôture.

**Rappel :** le nombre de déclarations et les structures de données sont déterminés par le code et SPEC 110 actuels, pas par cette fiche.
