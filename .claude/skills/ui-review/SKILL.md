# UI review
1. Inspect existing design tokens and components in public/ before editing.
2. Verify icon alignment, spacing, colors, typography, contrast, mobile overflow, focus and touch targets.
3. Compare screenshots across mobile and desktop when browser tools are available. Do not claim visual validation without rendering.
4. Make minimal changes and test relevant navigation and interaction states.
5. Report verified changes, viewport coverage and remaining limitations. Do not push or deploy without permission.
